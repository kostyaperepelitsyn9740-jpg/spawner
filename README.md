# Spawner Label (Minecraft 26.1.2 Fabric)

Клиентский мод, отображающий название моба над спавнерами.

## Способ 1: Сборка через GitHub (без установки Java и IDE на ПК)
1. Создайте бесплатный репозиторий на GitHub и загрузите в него распакованные файлы из этого архива (включая скрытую папку `.github`).
2. Перейдите во вкладку **Actions** в репозитории — сборка запустится автоматически.
3. Через 1–2 минуты откройте завершённый запуск и скачайте готовый `.jar` из блока **Artifacts** (`spawner-label-26.1.2-fabric`).

## Способ 2: Локальная сборка на ПК
1. Установите **JDK 25** (например, Eclipse Temurin 25).
2. Откройте папку проекта в **IntelliJ IDEA** (версии 2025.3+) и запустите Gradle-задачу `build` (или выполните `gradle build` в терминале).
3. Готовый файл появится в `build/libs/spawner-label-1.0.0.jar`.

## Установка в игру
Поместите `spawner-label-1.0.0.jar` и **Fabric API** для Minecraft 26.1.2 в папку `.minecraft/mods`.
